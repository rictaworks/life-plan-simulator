ログイン画面にはGoogleログイン、本人限定のサーバー保存、仮定による計算である説明を表示します。認証前に財務入力を表示しません。

ログイン後の上部にアカウント、ログアウト、未保存状態を常設します。設定では開始年月・期間・ケース名、収入・生活費・初期資産・率、同期する投資配分入力とスライダー、イベント編集を順に配置します。画面幅が狭い場合は1列とします。

計算操作により結果と月次明細を更新します。条件変更後には古い結果であることを示します。初期資産と月末資産を区別し、不足月で線と明細を終了します。比較は同じ開始・期間を共有する最大3ケースです。

保存管理では本人の一覧、保存、更新、読込、複製、個別・全削除を提供します。上書き・読込・サンプルによる未保存変更の消失と削除はアプリ内の確認ダイアログを用います。競合時には再読込を案内し自動上書きしません。認証失効では画面メモリーを消去し、別アカウントへ再送しません。

入力にはラベルと近接エラー、キーボード操作とフォーカス、色以外の警告を設けます。グラフと同じ値の表、計算前提、名目値・税・手数料除外を表示します。
