# Jev APIの固定証跡

現在の採用判断・公開サンプルの確認・承認記録は [../design-access.md](../design-access.md) を参照してください。

- `catalog.json`: 全94件のカタログの正規化コピー。元Git blobは `ec944a0369e14779cde9b9ceb6c0de2f02dc3766`。元と内容は一致しますが、ローカルの空白・末尾改行を含むバイト同一性は主張しません。
- `request.json`: APIが受理した実際の本文。全94候補を保持した7フィールドの一律射影と要件要約です。Authorization等のヘッダーは含みません。
- `response.json`: 実際の応答のmodel/answers/usage。全94件の確率を含みます。
- `preflight.json`: 人による採用承認より前に作成した選定時点の記録です。そこにある `adoption_status: pending ...` は当時の状態であり、後の人による承認を取り消すものではありません。
- `rejected-preflight.json` / `rejected-attempt.json` / `diagnostic.json`: 最初のサイズ超過と同一本文による診断用再試行の記録。失敗本文はリポジトリへ重複収録していません。成功前の最大要求数設定は当初計画であり、実際の3回のHTTP試行は別途明記しています。
- `corrected-attempt.json`: 候補数を維持したサイズ修正の実行記録。追加のJev評価は不要です。
- `sha256.json`: 同梱ファイルのSHA-256。内容の同一性確認用で、外部による署名・時刻証明ではありません。

APIの正確なstate/question別トークン数は不明です。ローカル推定器と提供元の計数は異なります。受理・実使用量は応答に記録されています。再実行して同一結果が返ることは保証しません。

入力には実際の給与・資産・イベント名・保存シナリオを含めていません。資格情報の値・Cookie・認証ヘッダーは保存していません。Jevは開発時のデザイン選定だけに使用し、アプリに外部AI接続を組み込んでいません。
